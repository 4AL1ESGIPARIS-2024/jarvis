# JARVIS

## Variables d'environnement

- `DISCORD_BOT_TOKEN` : Token du bot discord
- `CLIENT_ID` : Application ID du bot discord
- `GUILD_ID` : ID du serveur discord
- `BOT_VERSION` : Version du bot discord
- `LOGIN_MYGES_URL` : URL de login de l'api de MyGES
- `GRADES_CHANNEL_ID` : ID du channel discord pour les notes
- `USERNAME` : Nom d'utilisateur de l'api de MyGES
- `PASSWORD` : Mot de passe de l'api de MyGES
